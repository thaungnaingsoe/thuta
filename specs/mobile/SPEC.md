# Mobile application feature specification

Status: deferred phase 2; no Expo client has been implemented.

## Planned features

- Expo and React Native client using TypeScript.
- Public browsing, search, filtering, listing details, and photo viewing for Yangon, Mandalay, and Bago.
- Account sign-up/sign-in and listing creation and management through the sibling API.
- Shared Buy, Sell, and Rent intents, property types, and listing lifecycle with the web app.
- Responsive native layouts, accessible controls, and platform-appropriate secure credential storage.

## Acceptance criteria for phase 2

- Mobile uses the same API contract and account model as the web app.
- Visitors can discover public listings without signing in.
- Account holders can manage only their own listings through API-authorized operations.
- Mobile screens support common phone sizes and accessible touch targets.

Do not build mobile features until phase 2 is started and the API contract is stable.
